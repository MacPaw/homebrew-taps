MacPaw's [Homebrew tap](https://docs.brew.sh/Taps) listing the products that can be installed using Homebrew.

## Available products

| Name | Description | Installation command |
|------|-------------|----------------------|
| [CleanMyMac CLI](https://github.com/MacPaw/cleanmymac-cli) | Command-line interface for CleanMyMac | `brew install --cask macpaw/taps/cleanmymac-cli` |
| [Portable Memory](https://github.com/MacPaw/portable-memory) | Open, vendor-neutral `.mem` format and `mem` tool for AI memory | `brew install macpaw/taps/portable-memory` |

## Portable Memory

→ [Repository and documentation](https://github.com/MacPaw/portable-memory)

→ [Format specification](https://github.com/MacPaw/portable-memory/blob/main/Spec/portable-memory-spec.md) · [Paper](https://research.macpaw.com/publications/portable-memory) · [Swift SDK](https://github.com/MacPaw/portable-memory-swift)

The formula installs the `mem` command (`mem paste`, `ingest`, `validate`, `inspect`, `render`) from the Python reference SDK, which is published on PyPI as [`portable-memory`](https://pypi.org/project/portable-memory/). Portable Memory is open source under the [MIT License](https://github.com/MacPaw/portable-memory/blob/main/LICENSE).
